# Support

This file records the support policy for the Migration Stream source project
from World Class Consultants G.P. The project is maintained on a best-effort
basis and does not provide a service-level agreement, response-time commitment,
roadmap promise, or guaranteed fix or backport.

## Public issue scope

In the public clean repository, GitHub Issues accept:

- reproducible software defects through the bug form; and
- bounded product or engineering proposals through the proposal form.

Issues are project intake, not a usage-help or consulting channel. Do not open
support questions, troubleshooting requests without a reproducible defect, or
requests for delivery dates. GitHub Discussions is not enabled. Maintainers may
close reports that are not actionable or are outside the current scope.

Never submit client data, credentials, tokens, workspace files or databases,
raw logs, production metadata, screenshots, exports, generated reports, or
other confidential material. Use only synthetic or deliberately sanitized
reproduction material. See [Security](SECURITY.md) for private vulnerability
reporting and [Contributing](docs/CONTRIBUTING.md) for change proposals.

## Versions and platforms

The initial publication milestone is source-only `v0.1.0`. It does not include
public binaries and makes no supported-platform, installer, signing, or
notarization promise. Build and test evidence for a platform is not a support
commitment.

Before `1.0.0`, interfaces and behavior may change between minor versions. Once
public releases exist, maintenance focuses only on the latest published minor
line and the latest patch within that line, best effort. Superseded minor lines
do not receive promised fixes or backports.

## Commercial services

Any commercial assistance from World Class Consultants G.P. exists only under a
separate written agreement. The repository, an issue, a pull request, or a
public release does not create such an agreement or alter its terms.
